# Bazaro Market

A pan-African marketplace UI/UX prototype with Cameroonian products listed first.
Plain HTML, CSS and JavaScript. No build step and no backend.

## Pages
Home, search and results (filters, sorting), product detail, cart, checkout,
country stores, wishlist, orders and Seller Central (PrimeiT Solution).

## Run
Open `index.html` in a browser, or serve the folder:

    npx serve .

## Structure
- `index.html`: page shell (header, footer, mount point)
- `css/styles.css`: design tokens, light and dark themes, layout
- `js/app.js`: product data, hash router, views and state

All products, sellers, prices and reviews are sample data.
